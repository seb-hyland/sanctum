# Line structures

- Must show angles
  - Carbon double bond -> sp2 hybridized
- Don't need to put C or H
- For aromatic rings, prefer 3 lines in hexagon representation

# Substituted functional groups

## Alcohols/Halides

- Look at number of C atoms attached to the carbon with the functional group attached
- 1: primary, 2: secondary, 3: tertiary

## Nitrogen Compounds

- Look at number of C atoms attached **directly** to the nitrogen
